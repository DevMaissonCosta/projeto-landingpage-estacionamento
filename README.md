Prática com CSS Grid (Row & Column)
Sobre o projeto

Este projeto foi desenvolvido como parte dos meus estudos em CSS Grid, com foco no uso de:

grid-column
grid-row

O objetivo foi entender como posicionar elementos dentro de um layout utilizando linhas e colunas de forma estruturada.

 O que pratiquei

Durante este exercício, trabalhei com:

Criação de um container com display: grid
Definição de colunas e linhas com grid-template-columns e grid-template-rows
Posicionamento de elementos utilizando:
grid-column
grid-row
Estruturação de um layout semelhante a um site real
 Estrutura do layout

O layout construído possui:

Header → ocupa toda a largura no topo
Sidebar → posicionada na lateral esquerda
Main → conteúdo principal à direita
Footer → ocupa toda a largura na parte inferior
 Aprendizados
Entendi como o Grid divide a tela em linhas e colunas
Aprendi a usar grid-column para controlar largura dos elementos
Aprendi a usar grid-row para controlar altura e posicionamento vertical
Percebi a importância de definir corretamente início e fim (1 / 4, por exemplo)
 Desafios encontrados
Entender como o posicionamento automático do Grid funciona
Visualizar mentalmente as linhas e colunas
Ajustar corretamente os spans (início e fim dos elementos)
 Próximos passos
Aprender grid-template-areas
Trabalhar com responsividade usando Grid
Combinar Grid com Flexbox
Criar layouts mais complexos (dashboards, landing pages)
 Tecnologias utilizadas
HTML5
CSS3 (Grid Layout)
